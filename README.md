# Digital Slam Book

A fun, digital version of the classic school slam book. Friends fill in a short form about their memories and thoughts, and the responses show up on the page.

![Screenshot](screenshot.png)

## Features
- Welcome page with instructions before you start
- Slam form with questions like first impression, one thing you like, funniest habit, and describe me in one word
- Relation dropdown (Friend, Best Friend, College Friend, Roommate, and more)
- Option to submit anonymously
- Responses section that displays what friends have written
- Quick feedback section with yes/no questions and a suggestion box
